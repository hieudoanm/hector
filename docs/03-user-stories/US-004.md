# US-004: View current balance

## User Story
**As an** authenticated account holder,
**I want to** view my current account balance,
**so that** I know how much money I have available.

## Acceptance Criteria
- Given a valid access token, when I request my balance, then the system returns the current balance in minor units (cents) with currency code.
- Given an invalid or expired access token, when I request my balance, then the system rejects the request with a 401 error.
- Given a valid request, when the system responds, then the response includes the account ID and last updated timestamp.
- The balance reflects all completed transactions up to the last updated timestamp.
- Pending transfers are not deducted from the displayed balance until they complete.

## Technical Implementation Details

### API Endpoint
- **Method**: GET
- **Path**: `/api/v1/accounts/{accountId}/balance`
- **Headers**: 
  - Authorization: Bearer <accessToken>
- **Path Parameters**:
  - `accountId`: UUID v7 of the account whose balance is requested; it must belong to the authenticated user, otherwise the request is treated as not found (404 `ACCOUNT_NOT_FOUND`)
- **Success Response (200 OK)**:
  ```json
  {
    "accountId": "uuid (UUID v7)",
    "balanceCents": "integer (>= 0)",
    "currencyCode": "string (ISO 4217 format, e.g., USD, EUR)",
    "updatedAt": "string (ISO 8601 UTC timestamp)"
  }
  ```
- **Error Responses** (error envelope `{"error":{"code","message","details","requestId"}}`):
  - 401 UNAUTHENTICATED: Missing or invalid access token
  - 401 TOKEN_EXPIRED: Access token expired
  - 404 ACCOUNT_NOT_FOUND: Account not found or not owned by the authenticated user (avoids enumeration)

### Database Schema Changes
**Account Service Keyspace**
- Table: `accounts`
  - Columns:
    - `account_id` (UUID v7, primary key)
    - `balance_cents` (bigint, default 0)
    - `currency_code` (text, ISO 4217 format)
    - `updated_at` (timestamp)
    - `version` (bigint, for lightweight transaction handling)

### Security Considerations
- Account ownership enforcement: Verify that the authenticated user owns the account referenced by the `accountId` path parameter; a mismatch returns 404 `ACCOUNT_NOT_FOUND` (never 403)
- Balance amounts stored as integers in minor units (cents) to avoid floating-point precision issues
- Currency code validation against ISO 4217 list
- Timestamps stored in UTC timezone
- Use lightweight transactions (compare-and-set) for balance updates to ensure consistency
- No sensitive financial data exposed in logs or error messages

### Error Handling
- Missing or invalid access token: Return 401 with error code `UNAUTHENTICATED` and message "Missing or invalid access token"
- Expired access token: Return 401 with error code `TOKEN_EXPIRED` and message "Access token expired"
- Account not found or not owned by the authenticated user: Return 404 with error code `ACCOUNT_NOT_FOUND` and message "Account not found" (avoids account enumeration)
- Internal server errors: Return 500 with error code `INTERNAL_ERROR`
- Service unavailable (e.g., Cassandra down): Return 503 with error code `SERVICE_UNAVAILABLE` and Retry-After header

### Test Cases
1. Valid request with proper access token → 200 OK with account ID, balance, currency, and timestamp
2. Request with missing Authorization header → 401 Unauthorized
3. Request with invalid/malformed JWT → 401 Unauthorized
4. Request with expired JWT → 401 Unauthorized
5. Account with zero balance → Returns balanceCents: 0
6. Account with positive balance → Returns correct balance in cents
7. Account with maximum balance (9,999,999,999 cents) → Returns correct value
8. Balance reflects all completed transactions (verified against transaction history)
9. Pending transfers do not affect displayed balance
10. Timestamp updates when balance changes via transfer
11. Currency code is valid ISO 4217 format (3 uppercase letters)
12. Concurrent balance requests return consistent results
13. Balance query works after account creation (initial balance 0)
14. Verify no account information leakage in error messages
